# ✅ TODO List - Lista de Tareas 

Este proyecto es una aplicación web sencilla para crear, visualizar, completar y eliminar tareas, conocida como **To-Do List**. Desarrollada usando HTML, CSS y JavaScript, permite practicar eventos del DOM, almacenamiento en el navegador y lógica de interacción.

---

## 🎯 Objetivo del Proyecto

- Agregar nuevas tareas
- Marcar tareas como completadas
- Eliminar tareas individuales
- Almacenar las tareas localmente (usando LocalStorage, si aplica)

---

## 🧰 Tecnologías Utilizadas

- 🌐 HTML5
- 🎨 CSS3
- 💻 JavaScript (JS Vanilla)

---
